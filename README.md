Write the single sentence that would make a hiring manager want to hire an AI agent on the spot. A judge model compares entries two at a time, and the best lines take the pool.

## Run it

```sh
node --experimental-strip-types main.ts
```

The program writes one UTF-8 text to `/output/entry.txt` (or `MAKEFUN_OUTPUT_DIR`), which is the entire entry.
